# دروس دانشگاه — PWA

اپ تک‌صفحه‌ای برای جستجوی دروس، بررسی وضعیت هفتگی کلاس‌ها و پیدا کردن کلاس خالی. بدون بک‌اند، بدون فریم‌ورک — فقط HTML/CSS/JS خام.

## فایل‌ها
- `index.html` — کل اپ (UI + منطق)
- `database.js` — دیتای دروس، به‌صورت `window.COURSES = [...]`
- `manifest.json`, `service-worker.js`, `icons/` — برای نصب روی Home Screen و کارکرد آفلاین
- `fix_database.py` — اسکریپت پایتونی که دیتای خام رو تمیز می‌کنه (پایین توضیح داده شده)

## اجرا روی گوشی خودت (بدون سرور)
فایل `index.html` رو مستقیم باز کن — دیتا چون به‌صورت اسکریپت (`<script src="database.js">`) لود میشه، روی `file://` هم کار می‌کنه. برای نصب کامل روی Home Screen با پشتیبانی آفلاین واقعی (سرویس‌ورکر) باید از یه هاست استفاده کنی، چون سرویس‌ورکرها روی `file://` ثبت نمیشن.

## استقرار روی GitHub Pages
1. یه ریپو بساز و همه‌ی فایل‌های این پوشه رو داخلش بذار (ساختار پوشه‌ها رو دست نزن، `icons/` باید همون‌جا بمونه).
2. `Settings → Pages → Deploy from a branch` رو روی شاخه‌ی اصلی و پوشه‌ی روت تنظیم کن.
3. آدرسی که GitHub میده رو باز کن، از منوی مرورگر «Add to Home Screen» بزن.

## آپدیت کردن دیتا در آینده
وقتی فایل خام جدید دروس رو گرفتی:
1. `python3 fix_database.py` رو با فایل خام جدید اجرا کن (مسیر ورودی داخل اسکریپت رو عوض کن) تا `database.js` تمیزشده رو بسازه.
2. داخل `service-worker.js`، مقدار `CACHE_NAME` رو یکی بالا ببر (مثلاً `course-app-v2`) — این کار باعث میشه کاربرهایی که اپ رو نصب کردن، نسخه‌ی جدید دیتا رو بگیرن.
3. فایل‌های جدید رو push کن.

## نکات دیتا
- ۳۵۹۱ جلسه از ۳۲۳۶ گروه درسی با موفقیت پردازش شدن.
- ۵ مکان (آمفی تئاتر، سالن کنفرانس، کلاس جلسات دانشکده هنر، کلاس دویست‌ودو، آزمایشگاه مرکز رشد) عدد کلاسِ استخراج‌شده ندارن چون شماره‌شون عددی نیست یا اصلاً شماره نداره؛ در UI با همون نام کامل قابل جستجو و نمایشن.
- آیکون‌های داخل `icons/` موقتی و ساده‌ن — هروقت خواستی می‌تونی جایگزینشون کنی (همون سایزها: 192 و 512، هم نسخه‌ی معمولی هم maskable).
